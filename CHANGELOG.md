# Changelog

All notable changes are documented here.

## [1.0.0] - 2026-09-26

### Added

- Sixteen-chapter NPMplus security and operations guide.
- Threat model, trust boundaries, deployment controls, administration protection, TLS, ACME, HTTP/3, real-client-IP, OIDC, `auth_request`, mTLS, CrowdSec, AppSec, logging, monitoring, backup, recovery, upgrade, and incident-response coverage.
- Hardened Compose, environment, CrowdSec acquisition, and bouncer examples.
- Four read-only validation and evidence-collection scripts.
- Deployment, change, recovery, incident, and acceptance templates.
- Security policy, contribution guide, disclaimer, roadmap, supported-versions policy, architecture decisions, limitations, control catalog, and primary-source register.
