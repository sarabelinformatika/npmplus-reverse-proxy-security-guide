# Roadmap

## Planned

- Version-specific regression matrix for major NPMplus releases.
- Authentik, Authelia, and generic OIDC lab profiles.
- Prometheus/Zabbix monitoring examples and alert thresholds.
- External certificate-expiry and HTTP/3 validation workflow.
- Isolated restore-lab automation with explicit safety guards.
- Additional backend profiles for Nextcloud, Exchange publishing, WebSockets, gRPC, and large uploads.
- Signed release manifests and software-bill-of-materials guidance for supporting tools.

## Non-goals

- Replacing upstream NPMplus documentation or support.
- Guaranteeing application compatibility or protection against every attack.
- Publishing production secrets or turnkey Internet-facing defaults.
- Encouraging unsupported custom Nginx fragments.
- Operating a certificate authority, DNS provider, identity provider, or CrowdSec service.
